# Manual do Usuário 

## 1. Página Principal

Ao acessar a aplicação, o usuário é direcionado para a página principal
da Adornatta.

Nessa página, o usuário pode visualizar as principais informações e
seções da loja, incluindo:

-   Apresentação da Adornatta;
-   Categorias de produtos;
-   Produtos em destaque;
-   Informações sobre a loja;
-   Serviços e recursos apresentados pela aplicação.

## 2. Página Sobre

O usuário pode acessar a página **Sobre** para conhecer melhor a
Adornatta.

Nessa página são apresentadas informações sobre:

-   A proposta da Adornatta;
-   Os valores da loja;
-   A experiência oferecida aos clientes;
-   Os recursos disponíveis na plataforma.

Para acessar essa página, utilize a opção **Sobre nós** no menu de
navegação ou o botão correspondente apresentado na página principal.

## 3. Página de Produtos

O usuário pode acessar a página **Produtos** para visualizar as
semijoias disponíveis na aplicação.

Nessa página são apresentados os produtos cadastrados, contendo
informações como:

-   Nome do produto;
-   Descrição;
-   Preço;
-   Imagem;
-   Categoria.

## 4. Filtrar produtos por categoria

Na página de produtos, o usuário pode utilizar os botões de categoria
para filtrar os produtos apresentados.

As categorias disponíveis são:

-   **Todos**
-   **Brincos**
-   **Conjuntos**
-   **Pulseiras**
-   **Cordões**

### Como realizar um filtro

1.  Acesse a página **Produtos**.
2.  Localize os botões de categoria.
3.  Selecione a categoria desejada.
4.  A aplicação exibirá os produtos pertencentes à categoria
    selecionada.

Para visualizar novamente todos os produtos, selecione o botão
**Todos**.

## 5. Navegação

A navegação principal permite que o usuário alterne entre as páginas
disponíveis na aplicação.

Atualmente, o fluxo principal documentado neste manual contempla:

``` text
Página Principal
      │
      ├── Sobre
      │
      └── Produtos
              │
              └── Filtro por categoria
```
