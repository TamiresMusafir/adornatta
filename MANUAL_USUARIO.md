# Manual do Usuário 

## 1. Apresentação

A Adornatta é uma loja virtual de semijoias desenvolvida para
centralizar a consulta de produtos, a realização de pedidos e o
acompanhamento das compras.

A aplicação também possui uma área administrativa destinada ao
gerenciamento do catálogo, estoque, pedidos e vendas.

## 2. Página Principal

Ao acessar a aplicação, o usuário é direcionado para a página principal
da Adornatta.

Nessa página podem ser encontradas:

-   apresentação da loja;
-   categorias de produtos;
-   produtos em destaque;
-   informações sobre a Adornatta;
-   acesso às principais funcionalidades da aplicação.

A navegação principal permite acessar:

-   Início;
-   Produtos;
-   Categorias;
-   Sobre nós;
-   Contato.

Também estão disponíveis recursos de busca, conta do usuário, lista de
desejos e carrinho.

## 3. Página Sobre

A página **Sobre nós** apresenta informações sobre a proposta da
Adornatta, sua experiência e os valores trabalhados pela loja.

A página apresenta conceitos relacionados a:

-   qualidade;
-   cuidado;
-   elegância;
-   experiência de compra.

## 4. Produtos

Na página **Produtos**, o usuário pode consultar as semijoias
disponíveis.

Cada produto apresenta informações como:

-   nome;
-   descrição;
-   preço;
-   imagem;
-   categoria;
-   material;
-   tipo de banho;
-   disponibilidade.

## 5. Categorias

Os produtos podem ser organizados pelas categorias disponíveis na
aplicação:

-   **Brincos**;
-   **Conjuntos**;
-   **Pulseiras**;
-   **Cordões**.

### Como filtrar

1.  Acesse **Produtos**.
2.  Selecione a categoria desejada.
3.  A aplicação exibirá os produtos correspondentes.
4.  Para retornar à visualização geral, selecione a opção de todos os
    produtos quando disponível.

## 6. Busca de produtos

A busca pode ser acessada pelo ícone de pesquisa presente na navegação.

O recurso permite localizar produtos do catálogo sem precisar percorrer
toda a lista.

## 7. Detalhes do produto

Ao selecionar um produto, o usuário é direcionado para a página de
detalhes.

Nessa tela são apresentadas informações mais completas da semijoia,
como:

-   nome;
-   descrição;
-   preço;
-   material;
-   tipo de banho;
-   disponibilidade;
-   imagem.

A partir dessa tela, o produto pode ser adicionado ao carrinho.

## 8. Lista de desejos

A aplicação possui uma **Lista de Desejos**, permitindo salvar produtos
para consulta posterior.

Para acessar a lista, utilize o ícone de coração disponível na
navegação.

## 9. Carrinho de compras

O carrinho apresenta os produtos selecionados pelo usuário.

Nele é possível:

-   consultar os produtos selecionados;
-   visualizar quantidades;
-   alterar quantidades;
-   remover produtos;
-   consultar o subtotal;
-   seguir para o checkout.

## 10. Finalização do pedido

Para finalizar uma compra:

1.  Adicione os produtos desejados ao carrinho.
2.  Acesse o carrinho.
3.  Confira os produtos e as quantidades.
4.  Selecione a opção para finalizar a compra.
5.  Preencha os dados solicitados no checkout.
6.  Confirme o pedido.

O formulário do checkout possui validação dos dados informados.

Após a criação do pedido, o usuário é direcionado para o acompanhamento
do pedido.

## 11. Acompanhamento do pedido

Após finalizar uma compra, o usuário pode consultar o pedido por meio da
página de acompanhamento.

O pedido possui um identificador próprio e apresenta informações como:

-   identificação do pedido;
-   data;
-   valor total;
-   status;
-   produtos e quantidades relacionados.

Os possíveis status utilizados pelo sistema são:

-   **Em análise**;
-   **Em preparação**;
-   **Enviado**;
-   **Entregue**;
-   **Cancelado**.

## 12. Cadastro

O usuário pode criar uma conta pela opção de cadastro.

O formulário solicita os dados necessários para criação do usuário e
realiza validações antes do envio.

Após o cadastro, o usuário pode utilizar suas credenciais para entrar na
aplicação.

## 13. Login

Para entrar na aplicação:

1.  Acesse a tela de login.
2.  Informe o e-mail.
3.  Informe a senha.
4.  Confirme o acesso.

Após o login, a aplicação identifica o usuário autenticado.

Usuários com perfil administrativo possuem acesso à área administrativa.

## 14. Logout

Quando estiver autenticado, o usuário pode sair da conta utilizando a
opção de logout disponível na navegação.

Após o logout, a sessão armazenada no navegador é removida.

## 15. Área administrativa

A área administrativa reúne os recursos utilizados para gerenciamento da
loja.

O acesso é destinado ao usuário com perfil administrativo.

### 15.1 Dashboard

O dashboard apresenta um resumo da operação, incluindo:

-   total de produtos;
-   total de itens disponíveis em estoque;
-   produtos com estoque baixo;
-   produtos sem estoque;
-   atalhos para estoque, pedidos e vendas.

### 15.2 Gerenciamento de estoque

Na página **Estoque**, o administrador pode:

-   consultar produtos;
-   pesquisar produtos;
-   cadastrar novos produtos;
-   editar informações;
-   excluir produtos;
-   aumentar ou reduzir a quantidade disponível.

A página também apresenta indicadores sobre a situação do estoque.

### 15.3 Gerenciamento de pedidos

Na página **Pedidos**, o administrador pode:

-   visualizar os pedidos realizados;
-   pesquisar pedidos;
-   consultar os detalhes de cada pedido;
-   visualizar os produtos relacionados;
-   alterar o status do pedido.

### 15.4 Gerenciamento de vendas

Na página **Vendas**, o administrador pode consultar e registrar vendas.

A tela apresenta:

-   vendas realizadas;
-   vendas realizadas no mês;
-   faturamento do mês;
-   histórico de vendas;
-   busca por vendas.

### Como registrar uma venda

1.  Acesse **Vendas**.
2.  Selecione **Registrar venda**.
3.  Informe o cliente.
4.  Informe a data.
5.  Selecione o produto.
6.  Informe a quantidade.
7.  Selecione a forma de pagamento.
8.  Confira o valor calculado.
9.  Adicione observações, se necessário.
10. Confirme o registro.

Ao registrar a venda, o sistema verifica o estoque disponível e atualiza
a quantidade do produto.

## 16. Contato

A página **Contato** disponibiliza as informações e recursos destinados
ao contato com a Adornatta.

Ela pode ser acessada pelo menu principal.

## 17. Fluxo principal da aplicação

O fluxo de compra pode ser representado da seguinte maneira:

``` text
Página Principal
      │
      ├── Produtos
      │     │
      │     ├── Categorias
      │     ├── Busca
      │     └── Detalhes do produto
      │             │
      │             ├── Lista de desejos
      │             └── Carrinho
      │                    │
      │                    └── Checkout
      │                           │
      │                           └── Pedido
      │                                  │
      │                                  └── Acompanhamento
      │
      ├── Sobre nós
      │
      └── Contato
```

A área administrativa possui o seguinte fluxo:

``` text
Área Administrativa
      │
      ├── Dashboard
      │
      ├── Estoque
      │
      ├── Pedidos
      │
      └── Vendas
```

## 18. Encerramento

A aplicação foi estruturada para permitir que o cliente encontre
produtos, consulte seus detalhes, monte seu carrinho, finalize pedidos e
acompanhe o andamento da compra.

Para a administração da loja, o sistema centraliza o gerenciamento do
catálogo, do estoque, dos pedidos e das vendas em uma única aplicação.
