# Manual de Operação 

## 1. Iniciar a aplicação

Para iniciar o servidor de desenvolvimento, abra o terminal na pasta do
projeto e execute:

``` bash
npm run dev
```

Após executar o comando, o Vite iniciará o servidor de desenvolvimento e
apresentará no terminal o endereço local para acessar a aplicação.

Acesse o endereço indicado pelo terminal utilizando um navegador.

## 2. Parar a aplicação

Para interromper a execução do servidor de desenvolvimento, mantenha o
terminal que está executando o projeto selecionado e pressione:

``` text
CTRL + C
```

O servidor será encerrado.

## 3. Execução durante o desenvolvimento

Enquanto o servidor estiver em execução, as alterações realizadas nos
arquivos do projeto podem ser refletidas na aplicação pelo ambiente de
desenvolvimento do Vite.
